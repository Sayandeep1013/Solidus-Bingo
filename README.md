# Solidus Bingo

A full-stack Bingo game powered by Supabase.

## Stack
- Frontend: React / Next.js
- Backend: Supabase (Postgres, Auth, Realtime)
- Hosting: Vercel

## Getting Started

```bash
npm install
npm run dev
```

## Project Structure

```
src/
  components/   # UI components
  pages/        # Next.js pages
  lib/          # Supabase client and helpers
supabase/
  migrations/   # Database migrations
```
